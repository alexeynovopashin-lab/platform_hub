## Проверено 2026-10-10

- `_src/content/*.json` бакета открыты без пароля (`halls.json`, `prices.json`, `site.json` → 200; заголовок `no-cache`). Адрес вида `<сайт>/_src/content/halls.json`, а не `_src/halls.json` (тот даёт 404). Там же лежит `_src/render.mjs` и `manifest.json`.
- Из-за этого **секретов и памятки для персонала в `_src/` держать нельзя**.
- Заголовка CORS в ответе нет (**не проверен из браузера, по заголовкам ответа**): BroniOS с другого адреса из браузера напрямую не прочитает; с сервера / воркера читается. Если нужно из браузера — настройка бакета, это отдельная задача.
- Сборка с лишними полями зала (`amenities`, `windows`) в копии проекта прошла без ошибок, на страницы они не попали, в `_src/content/halls.json` попали. Значит, поля добавляются без поломки сайта.
- Админка на ветке `claude/step5-fixes` правит `prices.json`, `videos.json`, `events.json` (`src/render.mjs:417`); вкладки «Портфолио» и «Видео фотошколы» — на ветке шага 6b, не слиты в main.
- Чтобы админка правила новые поля, нужен новый вид правки в `adminEdit` (обычная выкладка сайта). Версия облачной функции меняется только при смене входа, бакета или фото.

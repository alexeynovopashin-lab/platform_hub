# Договор: свет в окнах зала

**Хозяин:** Light Plan (хозяин солнечной модели, 07.10 — см. `DECISIONS.md`). **Пользователи:** BroniOS (окно брони, админка), сайт студии. **Статус:** в работе — шаг Light Plan 31в (08.10, слово Алексея «нужна реализация сегодня»).

**Вход:** широта и долгота студии; момент времени; пояс зала (имя, например `Asia/Tomsk`); азимут окон зала (градусы от севера по часовой, куда смотрят окна); `hasWindows`.
**Выход:** `прямой` · `рассветный` · `закатный` · `рассеянный` · `нет окон` · `нет данных`. Пороги — константы, выбирает Light Plan, обоснование в справке. Утренний золотой час — «рассветный», вечерний — «закатный» (Алексей 08.10, A-008; Q-030).
**Не учитывается в первой версии:** погода, размер окна, преграды (дом напротив). Подпись честная: «по солнцу, без погоды».
**Форма поставки:** Swift (Light Plan) + самодостаточный JS-файл без DOM для BroniOS и сайта + числа сверки `Fixtures/window_light.json` + справка `light_plan:Light_Plan/docs/window_light_reference.md`. Пути — в отчёте шага 31в, впишутся сюда.
